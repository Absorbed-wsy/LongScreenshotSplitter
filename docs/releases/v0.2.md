## 全新界面与软件图标

- 浅色双栏界面：左侧分区设置，右侧长截图预览。
- 实时显示切片边界、预计张数和命名信息，调整参数即可查看变化。
- 增加空状态、就地参数校验、处理进度和完成反馈，切分期间锁定设置。
- 新增原创软件图标，覆盖窗口、任务栏与 Windows EXE，多尺寸 ICO 适配不同显示大小。
- 保留原像素切分、重叠区域、PNG / JPG / JPEG / WEBP 支持与同名文件保护。
- 扩充核心与 GUI 回归测试，新增自动构建、打包自测与 Release 发布流程。

## 下载

下载 `LongScreenshotSplitter-v0.2-windows-x64.exe` 后双击即可使用，无需安装 Python。

- `SHA256SUMS.txt`：EXE 的 SHA-256 校验值。
- `self-test.json`：发布包自测报告。

支持 Windows x64；EXE 未进行代码签名。所有图片均在本机处理。
